# Fork-only patches

Self-contained patches for **daily-driver-only** features that are **not** going upstream.
Kept here so they can be re-applied after an upstream history rewrite / rebase (upstream
periodically squashes/rebases its public history, so fork commits don't always replay cleanly).

## bank-editor-canvas.patch

On-device **Bank Editor** for OB-Xd via the host's `type:"canvas"` hook (no host changes) —
the movy-hybrid chassis, GENERATED by `../schwung-canvaskit` (v2) from `src/canvas.config.js`:
movy-style widgets (arc knobs, bar toggles, enum/value squares, ADSR graphic, name<->value label
swap), 13 banks / 76 params, SHIFT section-picker overlay (shift via the shadow_get_shift_held()
SHM binding — the shim doesn't forward CC 49 in chain-edit). See `CLAUDE.md` ("Bank Editor is
GENERATED") + the workspace worklog `_worklogs/schwung-obxd.md`.

Touches only: `src/canvas.js` (generated), `src/canvas.config.js` (source), `tests/canvas_*.test.mjs`,
`tools/render_canvas.mjs` (off-device previewer), `src/dsp/obxd_plugin.cpp` (+16 lines: `editor`
canvas chain-param, root menu entry, `editor_bank` get/set), `scripts/build.sh` (+1 line: package
`canvas.js`). Generated against pre-feature base `upstream/main` (v0.4.7 `57d03dd`). Note: after
re-applying on a fresh base you can also regenerate canvas.js from the config with the kit
(`node ../schwung-canvaskit/build.mjs src/canvas.config.js src/canvas.js`).

### Re-apply after an upstream rebase/reset

```bash
# clean apply (base unchanged):
git apply patches/bank-editor-canvas.patch

# if upstream moved obxd_plugin.cpp / build.sh and it won't apply clean, 3-way merge:
git apply --3way patches/bank-editor-canvas.patch
# (resolve any conflict in obxd_plugin.cpp — the +16 lines are additive and well-isolated)

# then verify:
node tests/canvas_helpers.test.mjs && node tests/canvas_banks.test.mjs && node --check src/canvas.js
```

To regenerate after further tweaks on `main`:

```bash
git diff upstream/main HEAD -- src/canvas.js src/canvas.config.js tests/canvas_helpers.test.mjs \
  tests/canvas_banks.test.mjs tools/render_canvas.mjs src/dsp/obxd_plugin.cpp scripts/build.sh \
  > patches/bank-editor-canvas.patch
```
